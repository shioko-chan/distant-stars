# Distant Stars

跨恒星系国家经营游戏，当前版本为 **0.5.0 地表规划原型**。设计依据为 [整体游戏设计基线](docs/design/distant_stars_game_design_baseline.md) 与 [技术方向](docs/architecture/technology_direction.md)。

## 运行与验证

```bash
npm install
npm run dev
npm test
npm run build
npm run preview
```

使用终端输出的本地地址。浏览器需支持 WebGL、模块 Worker 和 localStorage。

主题音乐默认开启；浏览器限制自动播放时，首次点击或键盘交互后开始播放。顶部显示当前曲名，可选择曲目、切换下一首或关闭音乐。六首原创配乐按顺序循环，由独立 Worker 按需本地合成，再通过 Web Audio 播放，无需安装音乐制作软件、下载音源或连接外部服务。准备期间仍可换曲或关闭，取消的曲目不会随后误播。关闭后保留播放进度，关闭期间选曲会在重新开启时从所选曲目开头播放。

| 曲目 | 时长 | 配器与结构 |
| --- | --- | --- |
| 遥远群星 | 1:30 | 原主题、大提琴对位、拨弦与圆号渐次加入，再回到微光中的主题 |
| 蓝色摇篮 | 1:19 | 6/8 钢琴与大提琴问答，八小节小调桥段，最后回归摇篮动机 |
| 日冕之帆 | 1:30 | 96 BPM 切分节奏、军鼓与过门，六小节失重间奏后在圆号主题中展开 |
| 漫长航路 | 1:35 | 无固定拍的低鸣、独奏大提琴与孤音，缓慢积累张力并保留深空留白 |
| 迟来的回声 | 1:24 | 错拍钟声与三音拨弦交织，主题拉长、反向回应并收束 |

每首使用独立的音符编排；十三种合成音色各有触发、衰减和泛音结构。各曲采用不同的空间衰减与混合比例，混音保留段落内的强弱与留白，并控制整曲响度和峰值余量。音符及曲尾均平滑释放。这里的钢琴、弦乐、圆号等仍是合成乐器，不使用真实乐器采样库。

## 首次游玩

应用先进入三维观景甲板：从黑猫身后望向落地玻璃舷窗。点击「开始」，猫跳上中控台，镜头在约 4.6 秒内转向终端并进入指挥界面；可跳过过场。中控台顶部的「观景甲板」会暂停时间并返回开场，保留游戏进度、目标选择和音乐状态。系统启用减少动态效果时直接进入中控台。

猫、桌台、终端、座椅和舱壁使用已下载的 GLB 模型，本地加载。来源与许可见开场的「模型鸣谢」及 [三维舰桥验证记录](docs/verification/bridge_intro.md)。

1. 选择邻星，批准无人探测器的建造与装载。初始速度为 0.01c，必须等待数百年的首程航行。
2. 等待期间选择太阳系，在人口政治、科研、经济与星球规划面板经营母星。月档适合观察，年档及更高速度适合航行等待。
3. 探测报告返回后，依据历史勘测决定是否拓荒，并设置发展目标、风险容忍度和地方授权。
4. 首个前哨报告返回时自动暂停。此后每五年发出地方报告，仍需经过光程。
5. 通过政策、预算、区域规划、轨道设施、补给航线、疏散和地方拓荒授权继续经营。
6. 历史面板可以追溯结果的原因。

## 调试控制台

默认关闭调试模式。在游戏地址末尾添加 `?debug=1`（已有查询参数时添加 `&debug=1`）并打开页面，然后点击顶部「调试控制台」，或在输入框外按反引号键（`）。关闭按钮或 Esc 可收起控制台；移除地址参数并刷新退出调试模式。

控制台提供确定性回放校验、模拟状态与最近响应耗时，以及最近 200 条诊断日志。可以点击快捷操作，也可以输入 `help`、`replay`、`status`、`clear`。回放校验会暂停时间，用本局种子与操作记录重算并比对当前状态，结果和耗时显示在控制台内；不会覆盖进度，校验后由玩家手动恢复时间。校验异常不会阻断存档或继续游戏。普通模式下不显示控制台，Worker 也拒绝回放校验请求。

验证范围见 [调试控制台验证](docs/verification/debug_console.md)。

- 五类实体库存、本地生产消费、价格、财政、税率、预算、债务和自动借还款。
- 每世界 12 个人口群体、四条政治轴、利益联盟、支持率、迁移、抗议、政体约束与政府重组。
- 五条研究方向、具名前置项目、时间估计、知识传播、当地技术部署。
- 探测、拓荒、地方自主选址、自持阶段、危机、货运、移民、返航疏散、地方自主探测与拓荒。
- 地表连续缩放与球面四叉树 LOD；直接绘制道路和七类分区，草稿撤销、预算预览、施工进度与道路连接反馈。既有人口与经济仍按 12 个区域汇总，新开发工程独立保存地理坐标。
- 一个固定文明与三处遗迹；延迟发现、接触政策、信任与发展变化、国内政治反馈。
- 灾害、自动修复、人口延续阈值、重大报告自动暂停、五年报告和百年总结。
- 手动保存、30 秒自动保存、读取、版本和结构校验、随机状态与行动日志回放。

## 工程边界

```text
src/content/       内容与主要平衡参数
src/simulation/    世界生成、经济、事件、命令与玩家查询
src/workers/       权威模拟入口
src/presentation/  Three.js 银河和星球
src/ui/            管理与命令界面
src/persistence/   存档编码和校验
```

帝国时间显示为年、月、日，月份之间按当前推进速度显示日期，支持实际月长与闰年。暂停或切换速度保留当月显示进度；读取存档回到已保存的月结算点。日级进度仅用于时间显示，不进入模拟或存档。

世界采用同一套聚合月结算，不随地图选择停止运行。报告和命令到达时间向上对齐月份，因此最多增加一个月结算延迟，不会提前于光速抵达。初版采用恒速航程，未模拟逐阶段加速与减速。

0.5 使用存档结构版本 3 和独立键 `distant-stars-save-v3`，不迁移或覆盖旧版本存档。损坏或内容版本不匹配的存档会提示开始新纪元，未成功初始化时禁止自动覆盖。

Electron 打包、完整外星国家外交战争、战术战斗、逐部件舰船设计和独立微观操作层仍按基线后置。

当前地表功能与验证范围见 [地表规划验证记录](docs/verification/surface_planning.md)。此前版本的测试证据与试玩边界见 [初版实现与验证记录](docs/verification/first_playable.md)。自动化长程验证不能替代 2～4 小时人工试玩和数值调整。

## 地表规划试玩

1. 选择太阳系，进入「恒星系」，点击地球，再点击「进入地球地表」。其他行星可查看独立情报；远方未知属性等待勘测报告。
2. 双击陆地连续靠近，滚轮调整高度；「全球视角」缩回整颗星球。
3. 选择「铺设道路」，在地表按住左键绘制；再用「分区笔刷」沿道路绘制住宅、工业等分区。
4. 查看预算，使用「撤销一笔」或「清空草稿」调整；点击「批准建设」。草稿仅保留在当前地表视图，离开前应批准或清空。
5. 推进时间，道路先施工；非保护分区在附近道路完成一半后开始建设。工程报告显示缺少道路、物资或稳定度等原因。
6. 使用「定位地表工程」回到已批准项目；建筑随进度增加。保存与读取会保留规划坐标和建设进度。

本次是自由绘制的首个闭环：支持自由手绘道路、分区笔刷和道路节点吸附，暂未实现矩形、多边形、已建工程拆除、桥梁、逐车交通、任意行星多殖民地或服务设施放置。地球使用程序化测试地貌；太阳系轨道半径和行星半径为示意参数，游戏宜居度与资源数值不代表真实天文结论。

### 太阳系影像与地形

太阳系已接入可署名使用的真实影像贴图，地球规划共用真实海陆与区域高程数据。精度约 20 km，农业与矿产是游戏估算。内容版本 0.6.0 需要开始新纪元。来源、许可、重建和验证见 [太阳系地形说明](docs/verification/solar_terrain.md)。

### 行星级开发

0.7.0 支持独立选择行星进行殖民、运输、经营与地表规划。太阳系可开发水星、金星和火星；成熟的太阳系殖民地可作为出发地。需要开始新纪元。详见 [行星级开发说明](docs/verification/planetary_development.md)。
## 飞船舷窗主界面

银河、恒星系和地表共用弧形金属舷窗，玻璃刻度与轻微反光叠在实时场景上。部门入口位于底部舰桥操控台；点击按键展开玻璃终端，再次点击当前部门、点击收起或按 Esc 返回观测。展开终端不卸载地图或模拟会话。时间、财政和人口读数集成在下方仪表区。

银河使用发光恒星和稀疏距离环。恒星名称可以直接点击；密集位置的标签会避让或隐藏，所有目标仍可通过恒星系选择器访问。窄屏下部门按键横向滚动，页面纵向滚动访问时间仪表。装饰窗框不会截获地图交互，减少动态效果设置会关闭终端进入动画。验证记录见 [舷窗界面验证](docs/verification/cockpit_ui.md)。

银河视图左下显示选中目标、距离和已确认情报的时间差，可直接进入恒星系、准备探测或打开情报。右下提供最新已收到报告和舰队入口；进入地表规划会收起管理面板。

远征授权仍使用现有表单。银河中可点击舰船标签，查看预计航程、出发或抵达倒计时与速度，并跳转目的地；舰队列表也可打开同一航程视图。选中舰船的航线会高亮。

金色圆环显示已知行政命令的去程位置，随模拟时间推进；抵达后隐藏并等待真正的执行报告。舰船任务授权不作为光速信号显示，不预演尚未收到的回程报告。连续镜头过渡尚未加入。
