# Distant Stars

跨恒星系国家经营游戏的首个可玩切片。当前版本围绕“探测、延迟情报、拓荒、地方自治与历史反馈”建立了完整闭环，整体设计以 `docs/design/distant_stars_game_design_baseline.md` 为准。

技术方向见 `docs/architecture/technology_direction.md`。项目默认继续使用工程化 Web 技术栈，并以独立模拟核心、React 管理界面和 Three.js 战略视图作为演进方向。

## 运行

```bash
npm run dev
```

然后访问 Vite 输出的本地地址（默认 `http://127.0.0.1:5173`）。首次运行前执行 `npm install`。

```bash
npm test
npm run build
```

## 已覆盖

- React + TypeScript 应用壳、Three.js 可旋转近邻星图。
- 固定种子的 20 个初始可观测恒星系。
- 连续帝国时间以及月、年、十年尺度的加速。
- 无人探测器与拓荒舰的亚光速航行、舰上固有时间和任务进度。
- 情报与报告严格按光速返回；界面区分发生时间、接收时间、确认状态和估计状态。
- 首次探测、勘测报告、拓荒舰、自主落点、前哨报告的完整流程。
- 本地人口、库存、工业、价格、支持率、稳定度、生态和自治度的自主演化。
- 传播中的政策命令、适应性授权、地方调整和可解释的因果报告。
- 五条科研方向和可部署的推进世代。
- 消息、命令记录、里程碑自动暂停、手动保存、自动保存和读取最近存档。
- 独立、确定性的模拟核心及关键时空规则单元测试。
