# Distant Stars

跨恒星系国家经营游戏，当前版本为 **0.4.0 初步可玩版**。设计依据为 [整体游戏设计基线](docs/design/distant_stars_game_design_baseline.md) 与 [技术方向](docs/architecture/technology_direction.md)。

## 运行与验证

```bash
npm install
npm run dev
npm test
npm run build
npm run preview
```

使用终端输出的本地地址。浏览器需支持 WebGL、模块 Worker 和 localStorage。

顶部「♪ 音乐关」可开启轻柔的太空主题音乐，再次点击关闭。主题曲由浏览器 Web Audio 本地合成，48 秒循环，无需下载音频或连接外部服务；每次打开页面默认关闭。

## 首次游玩

1. 选择邻星，批准无人探测器的建造与装载。初始速度为 0.01c，必须等待数百年的首程航行。
2. 等待期间选择太阳系，在人口政治、科研、经济与星球规划面板经营母星。月档适合观察，年档及更高速度适合航行等待。
3. 探测报告返回后，依据历史勘测决定是否拓荒，并设置发展目标、风险容忍度和地方授权。
4. 首个前哨报告返回时自动暂停。此后每五年发出地方报告，仍需经过光程。
5. 通过政策、预算、区域规划、轨道设施、补给航线、疏散和地方拓荒授权继续经营。
6. 历史面板可以追溯结果的原因，并校验本局确定性回放。

## 已接通的系统

- 固定种子、20 个初始观测恒星系；天文编目按需扩展到 100 个。
- 银河三维视图、简化恒星系轨道、可缩放旋转的三维星球。
- 固定月步长、日/月/年及高速控制、亚光速航行、舰船建造、装载、固有时间与延迟报告。
- Worker 独占权威状态；UI 只接收确认情报、已知任务、历史与估计区间。
- 五类实体库存、本地生产消费、价格、财政、税率、预算、债务和自动借还款。
- 每世界 12 个人口群体、四条政治轴、利益联盟、支持率、迁移、抗议、政体约束与政府重组。
- 五条研究方向、具名前置项目、时间估计、知识传播、当地技术部署。
- 探测、拓荒、地方自主选址、自持阶段、危机、货运、移民、返航疏散、地方自主探测与拓荒。
- 每世界 12 个区域，每区域 8×8 规划地块；七种功能、优先级、交通枢纽、轨道工程、自动建筑和历史损坏痕迹。
- 一个固定文明与三处遗迹；延迟发现、接触政策、信任与发展变化、国内政治反馈。
- 灾害、自动修复、人口延续阈值、重大报告自动暂停、五年报告和百年总结。
- 手动保存、30 秒自动保存、读取、版本和结构校验、随机状态与行动日志回放。

## 工程边界

```text
src/content/       内容与主要平衡参数
src/simulation/    世界生成、经济、事件、命令与玩家查询
src/workers/       权威模拟入口
src/presentation/  Three.js 银河和星球
src/ui/            管理与命令界面
src/persistence/   存档编码和校验
```

世界采用同一套聚合月结算，不随地图选择停止运行。报告和命令到达时间向上对齐月份，因此最多增加一个月结算延迟，不会提前于光速抵达。初版采用恒速航程，未模拟逐阶段加速与减速。

旧 0.3 存档不迁移。新档使用独立键 `distant-stars-save-v2`；不覆盖旧键。损坏或内容版本不匹配的存档会提示开始新纪元，未成功初始化时禁止自动覆盖。

Electron 打包、完整外星国家外交战争、战术战斗、逐部件舰船设计和独立微观操作层仍按基线后置。

具体覆盖、测试证据与试玩边界见 [初版实现与验证记录](docs/verification/first_playable.md)。自动化长程验证不能替代 2～4 小时人工试玩和数值调整。
