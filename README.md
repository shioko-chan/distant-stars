# Distant Stars

跨恒星系国家经营游戏的早期原型。当前仓库已实现单星球表面建设模块，整体设计以 `docs/design/distant_stars_game_design_baseline.md` 为准，单星球规则见 `docs/design/planetary_surface_construction_gdd.md`。

技术方向见 `docs/architecture/technology_direction.md`。项目默认继续使用工程化 Web 技术栈，并以独立模拟核心、React 管理界面和 Three.js 战略视图作为演进方向。

## 运行

```bash
npm run dev
```

然后访问 `http://127.0.0.1:4173`。Three.js 已存放在 `src/vendor/`，运行时不依赖外部 CDN 或安装额外包。

游戏平衡数值集中存放在 `src/data/game-balance.json`。区划成本与产出、人口容量、资源加成、枢纽成本、初始库存、建设速度和阶段阈值均可直接在该文件中调整；`npm run build` 会同时校验配置结构。

## 已覆盖

- 可旋转、缩放的 3D 星球。
- 基于固定种子的多尺度分形噪声生成大陆、海盆、山脊、局部坡面和浅沟。
- 地貌由海拔、湿度和纬度温度共同判定，而不是逐格随机指定。
- 22 个球面连续地貌区；同一区域由相邻、相似的地形单元组成。
- 宏观区域悬浮整区高亮，双击后直接在原星球表面显示对应的中观规划细节。
- 中观是唯一规划层级，地块可直接设置区划、建筑方向与交通枢纽。
- 滚轮放大会自动停止星球旋转，并像地图 LOD 一样按距离渐显球面网格、资源、区划和建筑；反向缩小逐层淡出。
- 中观采用球面焦点细化式 LOD：所选区域显示贴合曲率的 8×8 规划地块，星球其余部分继续保留并可双击切换焦点。
- 滚轮跨越层级时相机始终围绕星球中心推进，不改变观察中心；层级只描述当前可见的信息密度。
- 地形、资源点和灾害风险。
- 五种基础区块：住宅、工业、农业、科研、军事。
- 区块阶段成长：未开发到阶段 3。
- 简化人口、就业、产能、物流、幸福度、污染、稳定度和损毁。
- 交通枢纽与区块间物流可视化。
- 宏观战略、中观规划两档空间层级，各自拥有独立密度与尺度。
- 纯色、棋盘格和程序化纹理。
- 区块详情面板与星球事件日志。
- 常驻资源情报、地图悬停提示和区块实际加成说明。
- 可选择的公路、轨道和太空港枢纽，以及覆盖范围、吞吐、过载和物流增益反馈。
- 物流连线默认只显示当前区块相关连接，可切换为显示全部网络。
- 中观区域拆分为 8×8 最小规划地块，并使用连续三角网格渲染局部高程与侵蚀细节。
- 宏观与中观共享同一套球面方向采样；海岸线和生物群系位置保持不变，中观仅增加高频地表起伏。
- 双击快速靠近时保持原观察轴，只改变相机距离，不自动转向区域中心。
- 道路、资源点、枢纽和建筑会按局部地表高度放置。
- 游戏从 `2100年01月01日 00:00` 开始，以整小时推进；支持暂停、`1x`、`6x` 和 `24x` 流速。
- 已规划建筑随模拟时间累积建设进度，并在四个成长阶段切换模型复杂度。
- 五类区划拥有独立程序化建筑：住宅塔群、工业厂房与烟囱、科研塔与环形设施、温室农场、军事堡垒。
- 中观建筑会向上汇总：地块显示区划轮廓、密度与成长阶段，宏观星球显示对应的聚落簇和城市灯标。
- 行星经济包含信用点、建材、能源、食物和科研五种库存，并实时显示每小时净变化。
- 建设会立即扣除资源；工业生产建材、农业生产食物、科研区产出科研点，住宅提供住房与税收，军事区提供防御。
- 资源点、政策和交通枢纽会修改匹配区划的实际产出；能源或食物归零会触发供应短缺。
- 中观地块单击打开上下文规划选单，可在当前位置完成划区、建筑发展与枢纽建设。
- 面包屑和空间层级按钮用于返回上一级。

资源点仅对所在格的匹配区划生效，选单会直接说明匹配区划与实际加成。公路适合低成本短途覆盖，轨道用于高吞吐工业运输，太空港负责星外物流。
