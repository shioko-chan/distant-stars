# 星球表面建设 MVP

这是基于 `docs/design/planetary_surface_construction_gdd.md` 实现的 Three.js 交互原型。

## 运行

```bash
npm run dev
```

然后访问 `http://127.0.0.1:4173`。Three.js 已存放在 `src/vendor/`，运行时不依赖外部 CDN 或安装额外包。

游戏平衡数值集中存放在 `src/data/game-balance.json`。区划成本与产出、人口容量、资源加成、枢纽成本、初始库存、建设速度和阶段阈值均可直接在该文件中调整；`npm run build` 会同时校验配置结构。

## 已覆盖

- 可旋转、缩放的 3D 星球。
- 基于固定种子的多尺度分形噪声生成大陆、海盆、山脊、局部坡面和浅沟。
- 地貌由海拔、湿度和纬度温度共同判定，而不是逐格随机指定。
- 22 个球面连续地貌区；同一区域由相邻、相似的地形单元组成。
- 宏观区域悬浮整区高亮，双击展开对应的中观平面地图。
- 中观地块双击展开对应的微观建设布局。
- 地形、资源点和灾害风险。
- 五种基础区块：住宅、工业、农业、科研、军事。
- 区块阶段成长：未开发到阶段 3。
- 简化人口、就业、产能、物流、幸福度、污染、稳定度和损毁。
- 交通枢纽与区块间物流可视化。
- 宏观、中观、微观三档空间层级，各级拥有独立网格密度与尺度。
- 纯色、棋盘格和程序化纹理。
- 区块详情面板与星球事件日志。
- 常驻资源情报、地图悬停提示和区块实际加成说明。
- 可选择的公路、轨道和太空港枢纽，以及覆盖范围、吞吐、过载和物流增益反馈。
- 物流连线默认只显示当前区块相关连接，可切换为显示全部网络。
- 中观区域拆分为 8×8 地块，每个中观地块再拆分为 8×8 微观建设单元。
- 中观使用连续三角网格渲染局部高程；微观继承同一坐标并增加高频侵蚀细节。
- 道路、资源点、枢纽和建筑会按局部地表高度放置。
- 游戏从 `2100年01月01日 00:00` 开始，以整小时推进；支持暂停、`1x`、`6x` 和 `24x` 流速。
- 已规划建筑随模拟时间累积建设进度，并在四个成长阶段切换模型复杂度。
- 五类区划拥有独立程序化建筑：住宅塔群、工业厂房与烟囱、科研塔与环形设施、温室农场、军事堡垒。
- 微观建筑会向上汇总：中观地块显示区划轮廓、密度与成长阶段，宏观星球显示对应的聚落簇和城市灯标。
- 行星经济包含信用点、建材、能源、食物和科研五种库存，并实时显示每小时净变化。
- 建设会立即扣除资源；工业生产建材、农业生产食物、科研区产出科研点，住宅提供住房与税收，军事区提供防御。
- 资源点、政策和交通枢纽会修改匹配区划的实际产出；能源或食物归零会触发供应短缺。
- 中观或微观单击打开上下文规划选单，可在当前位置完成划区与枢纽建设。
- 面包屑和空间层级按钮用于返回上一级。

资源点仅对所在格的匹配区划生效，选单会直接说明匹配区划与实际加成。公路适合低成本短途覆盖，轨道用于高吞吐工业运输，太空港负责星外物流。
