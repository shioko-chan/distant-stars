## 历史与空间

历史清理前的 Web 分支为 `0b0011115d6720c15c2cd3e984b24b2d6b1923c3`。逐个重写其 12 个提交中的资源树，保留非资源文件、提交说明和作者信息；后续提交记录忽略规则与此说明。

Git 的对象库由所有分支共享。只清理 `web` 后，该分支的独立克隆无需下载居所素材；原仓库的 `main`、`unreal`、远程跟踪引用或 reflog 仍可能引用旧对象，因此原仓库的 `.git` 不会自动缩小。此次没有重写这些引用，没有在正在使用的仓库上运行垃圾回收，也没有推送远端。

后续同步代码应选择所需代码提交，避免把仍含旧素材历史的分支直接合并回 `web`。普通删除提交或 `.gitignore` 都不能阻止合并引入祖先历史中的大对象。

从已清理的仓库仅获取 Web 历史时使用 `git clone --single-branch --branch web <仓库地址>`；同一仓库已有完整本地对象库时，需通过传输协议克隆（本地路径可使用 `file:///绝对路径`），避免本地克隆直接复制共享对象库。
