## 证据与限制

本次是音频信号测量与项目乐谱检查，未进行主观听辨、乐器分离或准确扒谱。以下“改写方向”是创作判断，不是原曲的旋律、配器或和弦鉴定。没有将参考音频复制进项目或用于音频采样。

- 文件为双声道 Opus，48 kHz，解码时长 102.674 秒。
- FFmpeg 静音检测（低于 -60 dB、持续至少 0.5 秒）显示最后约 3.335 秒为静音，起点约 99.338 秒。
- 分析转换为 22.05 kHz 单声道，使用 4096 点 Hann 窗、220 点步长；对按频率归一化的正向对数频谱变化做自相关。
- 在 0–24、24–48、48–72、72–96 秒四个窗口，最强周期候选均约为 0.349 秒（约 172 次/分钟）。这是起音周期，不能据此断言四分音符速度为 172 BPM。约 86 与 114 等候选可能来自倍半速或节拍细分关系，拍号尚未确认。
- 同样算法对本项目已知 120 BPM 的《未寄出的星光》检测出约 120.3，说明在该对照上能找到节奏周期，但不能消除参考曲的节拍层级歧义。

## 修改前的 120 BPM 版本在谱面上的问题

检查 `src/content/music.ts` 的 `unsentStarlight()`：

1. 主动机每次几乎都是四个等长起音，只有音区、音色和整体力度发生变化。
2. 主体回应只有两种四音轮廓；主题与回应轮替，缺少跨越更长段落的旋律发展。
3. 和弦按固定两小节一换、八组循环进行；低音与反拍持续重复。
4. 中段连续交接完整四音，但旋律发展幅度有限；再现主要依赖加层。

这些是代码可直接确认的结构特征。“因此可能显得机械、缺少方向”是创作判断，最终仍需用户听感检验。

## 据此确定的改写方向

保留 B–C–E–G 的音序和连续性，把它放进更长的乐句，而非每两小节重放一次完整模板：

- 首次清楚呈示四音，随后用下行回答、延长句尾、短暂停顿形成四至八小节的完整呼吸。
- 连续不等于等长：四音之间可以不停顿，同时改变时值、起拍位置与重音。
- 伴奏承担稳定的细分脉冲，旋律可以跨拍延伸；避免所有声部同时按相同格子起落。
- 中段真正收低与让位，再通过旋律音区、和声张力、对旋律和动态共同推进。
- 不依据当前测量猜定参考曲的乐器，不把原曲旋律或音频复制到新作品中。
