# 初版实现与验证记录

版本：0.4.0。依据：整体游戏设计基线与技术方向。此记录描述最终运行路径，不把界面文案当作实现证据。

## 设计对应

| 基线要求 | 实现位置与行为 |
| --- | --- |
| 银河与生成 | `generation.ts` 每个恒星按种子和索引独立生成；初始20个，编目扩展到100个。未勘测对象的环境、资源、风险和异常不会进入玩家查询。 |
| 连续经营、统一时间 | `world.ts` 使用整数月 tick；界面批量推进不改变结算结果。月内到达向上对齐，所有事件保持因果顺序。 |
| 舰船与距离 | 建造成本与实际货物分别扣除；0.01c 初始探测，技术上限0.25c；显示帝国航程、舰上时间及预计抵达。可靠性事件记入历史。 |
| 情报隔离 | `queries.ts` 从已接收快照和已知命令/舰船构建 PlayerView；Worker 不向 React 发送权威 worlds、待收 signals、实际远方命令结果。 |
| 命令闭环 | 来源、目标、预算、优先级、期限、风险、授权、默认行为均存档；旧命令不能撤回；同刻命令按顺序号执行。支持执行、调整、推迟、拒绝与延迟回执。 |
| 自主经济 | `economy.ts` 五类库存、生产消费、产业、价格、财政余额、收入、支出、债务、利息、承诺和借款上限按月变化。货币不能替代当地物资。 |
| 人口政治 | 12个地区职业群体具有年龄结构、教育、认同、生活水平、支持率与四条价值轴。按利益聚合联盟；迁移、政策阻力、罢工、政府重组和分裂采用聚合规则。 |
| 科研 | 五方向并行机构项目、方向重点和预算、前置知识、0.85–1.15项目难度范围；成果通过通信传播，部署受教育和高级部件限制。 |
| 拓荒 | 勘测确认→建造装载→航行→本地选址→前哨→自持与发展→报告返回；具备当地条件且获得授权的世界可以自行探测和拓荒。 |
| 运输救援 | 民生优先航线根据已接收的库存周期评估；货运物资到船抵达才加入库存。移民通过客运船；疏散命令到达后使用当地已抵达船舶返航。 |
| 星球规划 | 12区域×64地块，支持单地块或整区域功能，普通建筑与道路自动生成；建设受地形、库存、预算、政治和物流限制。宏观球体与近距离规划仍为同一球面。 |
| 智慧生命 | 固定文明目标和遗迹需要近距探测；五种接触政策影响信任、发展和国内群体反应。不是完整外交或战争模拟。 |
| 历史与失败 | 地方五年报告、研究与执行报告、环境灾害、百年总结、前哨生存危机与帝国人口失败。重要报告到达后暂停。 |
| 存档与回放 | `save.ts` 版本与结构校验；保存随机状态、在途信号、世界、知识和行动日志；`replay` 从种子和行动重算同一世界。 |
| 技术栈 | React+TypeScript+Vite+Three.js+Vitest；模块Worker运行模拟，UI只接收查询。未添加运行时依赖。 |

## 验证

最终自动化结果：19 项测试全部通过；TypeScript 检查与 Vite 生产构建通过。

自动化覆盖：星图确定性与距离、0.01c起步、报告传播、拓荒与政策往返、隐蔽状态隔离、旧命令顺序、非法政体政策、时间批量不变性、存档与回放、600年无人干预、政策分歧、实体运输、固定文明接触、重大报告暂停、单地块规划、地方自主发射、疏散以及8世界/100舰船负载。

本机一次负载测量：8个已有人口世界、100艘在途舰船、100年结算约1.5秒，存档约775 KiB。该数据是无渲染模拟测试，不是端到端帧率保证。界面显示每次Worker操作耗时。

生产构建浏览器检查已确认：

- 银河画布与管理界面可用；选择目标、建造探测器、财政扣款与重复任务限制生效。
- 高速推进后收到近距勘测，母星人口、支持率和科技持续变化。
- 可以依据历史勘测批准拓荒。
- 恒星系入口、三维星球、12区域和64地块规划控件能显示。
- 内容版本不匹配时展示明确错误，允许开启新纪元。

后续浏览器交互读取被自动审批以使用额度耗尽为由拦截。因此最后一轮生产页面中的“首次前哨暂停→单地块提交→保存读取→回放按钮”未完成连续人工复核；对应模拟路径有自动化测试，不能据此声称人工复核已经通过。

## 初版抽象与试玩边界

- 采用固定月经济结算与恒速星际航程；信号向上对齐月份，不早于光速。日档累计到月才结算。
- 恒星系内运输、普通企业与利益集团均聚合结算，不建立个体公司、选举候选人或战术单位。
- 同一个星球使用12个地区人口群体与区域级建设进度；地块决定功能配比，不单独模拟每栋建筑。
- 所有已实例化世界使用相同聚合公式。未实例化的空恒星不结算经济，远方已有世界不会因为未查看而冻结。
- 初版智慧生命是固定接触案例，不包含外星星际国家竞争。
- 数值、科研估计区间和时间档已可测试；尚未完成2～4小时真人体验验证，不能声称已验证15分钟理解情报、30分钟首次重要决策、每10～20分钟反馈等体验指标。
- 星球模块旧文档中的2100年起点、小时级经济和旧原型配置路径与整体设计冲突；当前以整体设计为准，主要平衡值集中于 `src/content/catalog.ts`。

## 建议试玩脚本

1. 母星采用均衡政策，发出一艘探测器，体验等待期间的国家经营。
2. 相同种子分别使用工业动员和生态优先，推进100年，比较历史曲线与区域污染。
3. 首份探测报告返回后拓荒，记录实际建立时刻与中央得知时刻。
4. 连续发送两条相反政策，确认旧命令不会自动撤销。
5. 建造货船，观察当地物资不会在付款时瞬间增加；再测试返航疏散。
6. 发现智慧文明并比较观察、交流与竞争；跟踪两地政治和信任变化。
7. 保存、读取、校验回放；记录整个2～4小时体验中的决策密度与难以解释的结果。
