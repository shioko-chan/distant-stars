# 太阳系影像与地球地形（内容版本 0.6.0）

## 实现范围

- 太阳、八大行星使用 Solar System Scope 2K 图像；恒星系选中行星显示 Three.js 球面贴图预览。
- 地球表面使用同源日间影像、海陆遮罩，以及 NASA Blue Marble / GEBCO 高程。只有地球拥有真实高程，其他太阳系天体目前仅影像预览；巨行星影像代表大气层。
- `terrain.ts` 为模拟和地表网格提供统一经纬度、高程、区域坡度和资源估算。地球 2048×1024 数据约 20 km/采样（赤道），原高程图范围 0–6400 m，地形不夸张。连续缩放不增加数据精度。
- 路径按约 6 km 间隔检查中心和横向笔刷范围。海域不可施工；道路最大区域坡度 12°，分区 8°；坡度每 5°增加一倍基础造价，同时按相同系数减慢施工。
- 非保护分区沿线需要附近完成至少 50% 的道路。局部农业产出乘以 `0.25 + 农业适宜度`，工业乘以 `0.5 + 矿产潜力`；失去道路条件时停止产出。
- 农业适宜度为影像颜色代理，矿产潜力为高程/坡度规则，均非现实资源调查。12 个区域的地形属性与显示位置也改为同一数据源。
- 内容版本更新，旧存档会明确提示开始新纪元；不迁移旧随机地形上的工程。

## 数据来源与重建

完整署名、许可和处理说明见 [公开来源页](../../public/textures/solar/sources.html)。

1. Python 执行 `scripts/fetch_solar_assets.py` 下载原始图像和高程；仅此步骤需要网络。
2. 安装 Pillow 后执行 `scripts/prepare_earth.py`。每个格点为 little-endian 16 位：低 11 位海拔/4 m，第 11 位陆地标记，高 4 位农业适宜度；生成的 JSON 直接供主线程和模拟 worker 使用。
3. 原始 TIFF 不提交也不随站点发布；JPG、生成的 JSON 和署名页提交。运行时不依赖外部图像服务。
