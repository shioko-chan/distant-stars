# 行星级开发（0.7.0）

## 可用流程

1. 在恒星系点击行星，或使用顶部「目标行星」选择器。
2. 在运输面板向目标发出探测、殖民、货运或移民任务。太阳系岩质行星开局已有勘测，可直接殖民。
3. 抵达后该行星拥有独立人口、库存、财政、科技部署、政策、历史与地表工程。经济与规划面板随行星选择切换。
4. 成熟的太阳系轨道工业可以作为新的出发地；资源从所选出发行星扣除。远方出发仍由地方拓荒授权组织，避免绕过通信延迟。

## 模拟规则

- `worlds` 和 `intel` 按行星 ID 索引，命令、舰船、知识信号、补给航线均指向行星。恒星系 ID 仅用于星图、所属关系和恒星系尺度距离。
- 开发火星不会覆盖地球；探测一个系外行星不会自动揭示同系其他行星的资源与宜居度。
- 系内航程用两行星轨道半径之和估计距离（AU 转光年），并按既有速度计算；抵达时间向上取整到月。因此运输至少经历一个月，而不是零距离瞬移。这不是轨道转移力学模型。
- 同一太阳系的通信在月度模拟内视为即时；系外通信继续遵守光程与返回报告延迟。
- 工程预算按目标行星半径计算；各行星独立生产与施工，资源产量采用各自行星资源属性。
- 气态行星尚无地表殖民。水星、金星、火星使用真实影像和可规划平坦球面，尚无真实高程；地球仍使用已接入的高程数据。
- 内容版本更新为 0.7.0，旧版按恒星系索引的存档不迁移，需要开始新纪元。

## 验证

新增 `planets.test.ts` 覆盖双行星殖民、母星保留、目标独立政策与施工、货物准确入库、太阳系殖民地出发、拒绝无效目标与气态殖民、单行星探测范围、存档及确定性回放。原有跨星系延迟、地方自治、疏散、百年规模测试继续执行。

浏览器视觉验收仍受先前自动审批的浏览器用量限制阻挡，未声称完成。
