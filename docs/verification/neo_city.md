# Neo City 场景接入验证

2026-09-27。

## 实现

- 从 KitBash3D Neo City 原件制作 8 种建筑，在原有布局的 40 个地块上替换程序建筑。左右窗各保留一组，后窗保留两组，其余按适配程度分配；选址考虑房间比地面高 240 m，避免新楼全部藏在窗台下。
- 其中 4 处标志建筑按窗洞和周边遮挡选址，保证上部立面能从左右及后窗看到；回归测试检查这些视线。
- 新模型使用统一缩放，宽、深、高均不超过原地块包围体；保持街道、房间清空区与向旋转轴的重力方向。原建筑在两个程序 LOD 中都被移除。
- 1,200 m 内选高细节层，超出后选同一建筑的中细节层；切回高细节使用 12% 回差。不同实例共享几何、材质、贴图，逐楼视锥剔除后填入批次。
- 替换建筑不承载原程序空桥和停机坪，仍保留为交通障碍物。加载中的场景卸载会等待模型 Promise 结束，再释放迟到场景和 Draco worker。
- 原始 Blender 文件与 384 张 4K PNG 保留在素材归档。运行时约 43.4 MB，使用 34 种材质、103 张共享贴图；主要立面的色彩与法线保留 4K，其余按表面贡献分配分辨率。纹理 GPU 分配估计为 331 MiB，包含 mipmaps，不等于下载体积。

素材规格与许可见 [运行时说明](../../public/models/neo-city/README.md)，重建步骤见 [转换管线](../../scripts/city/README.md)。

## 自动验证

- `npm test`：25 个测试文件、146 项测试通过。
- `npm run build`：TypeScript 与 Vite 生产构建通过。
- 真实素材尺寸参与窗口可见性及左右／后窗分布回归测试；另覆盖原地块边界、原建筑移除、LOD 同位、回差、共享批次裁剪和交通障碍保留。
- 独立解码全部 244 个 Draco primitive，检查索引、有限坐标、UV、材质引用、103 张贴图、8 个高细节模型的底部原点与包围盒，全部通过。完整报告位于 `asset-sources/city/kitbash3d/neo-city/conversion-validation.json`。
- 浏览器中延迟几何下载后立即卸载，随后产生的 2 个解码 worker 均被终止，剩余 0。
