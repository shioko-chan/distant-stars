# 调试控制台验证

2026-09-19。

## 行为

- 启动地址添加 `?debug=1` 显式启用调试模式；普通模式没有控制台入口、快捷键或历史回放校验按钮，Worker 拒绝回放校验请求。
- 顶部按钮或输入框外的反引号键打开控制台；关闭按钮和 Esc 收起。关闭保留当前会话的最近 200 条日志，刷新清空。
- 快捷按钮与 `help`、`replay`、`status`、`clear` 命令提供帮助、确定性回放校验、状态记录和日志清空。未知命令输出错误提示。
- 校验先暂停时间，结果和耗时留在控制台中，不覆盖玩家通知或当前世界。通过、不一致、校验异常分别处理，后两者不会作为模拟致命错误。
- 状态读数使用玩家已有视图及 Worker 响应耗时；没有新增远方真实状态查询、存档字段或依赖。
