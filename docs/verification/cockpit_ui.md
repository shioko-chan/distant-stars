# 飞船舷窗界面

## 视觉与交互

- 舷窗采用弧形多层金属边框、侧向支撑、玻璃反射和冷色刻度，结构参考 [NASA Cupola 观测舱](https://www.nasa.gov/international-space-station/cupola/)。装饰均由 CSS 和 SVG 构成，没有新增图像下载或运行时依赖。
- 部门菜单改为底部舰桥按键，日期、财政、人口和推进速度放入下方仪表。目标、收到的报告及航行详情仍在观测窗内显示。
- 经营面板使用可滚动的玻璃终端；按钮和 Esc 可以收起，地图及唯一模拟会话持续挂载。
- 银河移除平面方格，采用距离环、发光恒星及固定种子的背景星空。名称优先展示当前目标和母星，在投影空间避让；无法容纳的标签隐藏，恒星选择器继续列出所有目标。
- 恒星名称支持键盘操作；装饰层不接受指针事件。使用系统的减少动态效果设置时，关闭界面动画与过渡。
- 恒星系和地表工具共用舷窗布局。行星缩略图保持方形画布并跟随容器缩放，避免窄面板横向溢出。
