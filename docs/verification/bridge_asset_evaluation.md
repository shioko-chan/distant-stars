# 高精度舰桥候选评估

评估日期：2026-09-19。

## 结论

**不采用 Nikitos & 3130 的 Spaceship 作为开场舰桥，也不建议投入成本将其改造成目标场景。**

它是现实空间站舱段风格的内景，在线模型呈现明显的扫描重建特征。31.3 万三角面的数量不代表适合近距离观察的精细工业建模。我们需要的是宽敞、先进、有落地观景窗和可用中控台的舰桥，两者在空间结构与表面质量上均不匹配。

## 视觉检查

在 Sketchfab 在线查看器中检查了最终材质视图、去除颜色纹理的 Matcap 几何视图，并旋转镜头观察近景。

- **空间与构图：** 初始视角是狭窄的连续舱段，画面充满管线、仪器、软包和舱门。已检查视角没有满足需求的落地观景窗或开阔中控区域，不能直接承接黑猫背后望向星海的构图。
- **几何质量：** Matcap 下，舱壁、门框和设备边缘有明显的不规则起伏与粘连，缺乏干净的硬质表面轮廓。这是对实际显示的观察；“扫描重建”是据此作出的推断，作者未在页面明确说明制作方式。
- **材质质量：** 信息面板标注无 PBR，检查器仅列出 Base Color。现有明暗和表面细节主要呈现在颜色贴图中；不能指望替换灯光就获得清晰的金属粗糙度变化、玻璃反射与局部仪表发光。要达到目标，需补做材质乃至重做表面。
- **镜头与动作：** 当前开场需要猫从地面跳到约 1.05 米高的台面，随后相机沿弧线接近屏幕。这个资产的现有舱段构图无法直接提供所需台面与镜头走廊，至少需要重新设计舱室、窗口和中控台。
- **可编辑结构：** 未取得源文件，未确认独立网格、物体命名、真实尺寸或拓扑连接方式。因此不声称可以直接拆出可用的桌台、门或设备，也不把 5 个材质等同于 5 次绘制调用。

## 后续资产筛选标准

优先筛选 CC0 或 CC BY 的人工硬质表面建模资产，先看近景与去贴图视图，再看面数。至少需要：

1. 宽敞观景区域，能安排大面积玻璃和猫的第三人称镜头。
2. 舱壁、窗框、桌台、屏幕可独立调整；桌面有明确可落脚区域。
3. 干净的几何轮廓、真实倒角以及可重设灯光的材质；金属、塑料、玻璃和发光部件可区分。
4. 提供颜色、法线、粗糙度、金属度等适用贴图，并确认转换后的 glTF 材质仍可用。
5. 先用完整近景与猫跳台的固定镜头验证效果，通过后再做贴图压缩、网格优化和目标设备性能检查。

若完整舰桥难以同时满足条件，优先保留按需求设计的观景空间，再替换高质量中控台、座椅、舱壁等独立部件，而不是迁就一整套不合适的内景。
