# 静止观测者运动示意

- `observer-motion.svg`：独立 SVG / SMIL 动画，无脚本、字体下载或外部图片依赖，可直接用浏览器打开。
- `observer-motion.html`：同一动画的交互预览，支持暂停、重播、速度选择和主图时间拖动；系统要求减少动态效果时默认暂停。

运行项目后访问 `/diagrams/observer-motion.html`。也可以直接打开 HTML 文件。

## 参照系与时间

“静止”指观察者相对房间不走动、不转头。星环的 −Z 轴始终指向地球，并继续绕自身 +Z 轴快速自转。左图跟随环心平移和缓慢对地转向，但不随星环快速自转；右图是固定房间坐标中的视野。主图 24 秒重播从初始时刻起的一个星环自转周期（约 245.73 秒）。地球中心在房间中的方向保持固定，太阳与星空的运动同时包含快速自转和缓慢对地转向的反向变换。每轮末尾回到初始时刻，太阳与恒星会重播这同一段时间。

下图采用独立时间比例，32 秒演示一圈地心公转（约 11.22 小时），同时展示环心位移和星环姿态变化。星环圆周按三维环平面投影，青色轴线的箭头始终朝向地球；圆周没有快速自转标记，以免独立加速时产生采样混叠。星环图标已放大，太阳距离已压缩，太阳方向与公转轨迹使用相同的空间投影。自转轴始终位于公转平面内，与公转轴垂直；每公转一圈，对地姿态也转向一圈。

项目按运动学约束直接给定对地姿态：从星环局部坐标到惯性坐标的旋转为 `Ry(公转角) × Rz(自转角)`，天空使用其逆变换。图示与实现均未模拟维持姿态所需的控制力矩。观测者到环心的有限偏移仍保留，因此地球位于房间中的固定方向，但不严格落在观测者自身的 −Z 射线上。

天体中心直接采样 `earthPositionFromStation` 和 `solarPositionFromStation`，恒星使用完整的 `inertialOrientationFromStation` 变换。右图沿初始镜头朝向投影，垂直视场扩展至 60°，便于展示太阳轨迹。地球位置固定，但受光方向仍会变化。圆盘和明暗为示意；太阳保留小圆盘并加光晕。省略地球表面纹理自转、云层、月球、其他行星及建筑遮挡；没有添加项目未实现的年度绕日公转。

## 重新生成

在项目根目录执行（使用现有开发依赖）：

```sh
node_modules/.bin/vite-node scripts/diagrams/observer-motion.ts
```

源文件：`scripts/diagrams/observer-motion.ts`。参数来自 `src/presentation/habitatFrame.ts`、`stationOrbit.ts`、`bridgeMotion.ts` 和 `src/content/solarSystem.ts`。生成器不会修改游戏运行代码。
